## Professional profile

I make engineering teams faster. Lately that means making AI coding assistants a dependable part of how a team ships, rather than a personal trick.

## OpenCastle

I created [OpenCastle](https://www.opencastle.dev/), an open-source CLI. A team writes its AI assistant config once (instructions, agents, skills, commands and MCP servers) and OpenCastle compiles it for Claude Code, GitHub Copilot, Cursor, Windsurf, OpenCode, Codex and Antigravity. It treats that config as part of the engineering standard: shared baselines published as npm packages, a policy that can only tighten, a lock file, and a CI check that fails the pull request when generated config drifts from its source.
